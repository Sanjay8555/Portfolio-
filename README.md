## 🌟 Key Features

- **Constellation Particle Mesh Canvas**: Zero-dependency interactive particle network that dynamically connects nodes in real time.
- **Interactive Project Sandboxes**:
  - 🏍️ **Smart Helmet IoT Live Simulator**: Test real-time IR sensor detection, MQ-3 alcohol sobriety threshold interlocks, engine ignition state, and simulate crash impacts with automatic GPS & GSM emergency dispatch.
  - 🎓 **ERP Student Management System Sandbox**: Switch roles (Admin / Faculty / Student), log attendance batches, calculate semester GPAs, and simulate fee invoicing ledgers.
  - 🏛️ **Public CRM Grievance Redressal Portal**: Lodge simulated civic tickets with geotagged locations, automated departmental dispatching, and live SLA countdown progress.
- **Developer CLI Terminal Easter Egg**: Fully functioning in-browser terminal emulator (`sanjay@portfolio:~$`) with commands like `help`, `skills`, `projects`, `education`, `certs`, `contact`, and `sudo hire`.
- **Theme Switcher**: Seamless toggle between sleek Cyber Slate (Dark) and Modern Crisp (Light) mode with localStorage memory.
- **Printable Resume Viewer**: One-click printable and copyable formatted resume with print-optimized CSS rules.
- **Skills Matrix Filter**: Categorized interactive filter for Languages, Web & Backend, IoT & Hardware, Data & Tools, and Soft Skills.
